# World State boards

Notes for this folder. The rules that apply everywhere, the commands and the list of the other notes are in the root `CLAUDE.md`.

**World State boards** (`src/discord/feeds/`, migration 36, `test/feeds.test.ts`): seven channels, each holding one live Components V2 board that `syncBoard` keeps current (board id `feed:<id>`): `alerts` (each alert with its reward, node and levels, an event's missions folded into one line by `groupAlerts` (worldstate.ts, shared with the status page), events with progress and interim rewards, then Nightwave), `arbitrations` (the best of the week, the next 24 h, later, the one running now; a "Plan ahead" button and menu, `planMessage`, list S/A for 14 days, B or better for 7, C or better for 3; its "Squad up" button was removed at the owner's request on 2026-11-16, and a leftover `feeds:squad` tap, also in a DM, is told so and pointed to `/lfg`), `fissures` (normal, Steel Path, Void Storms, by tier; its menu also offers "Crack now: my own relics", the `crack` notification of `src/discord/crack.ts`, which `handleFeedSelect` only sets for a member whose AlecaFrame link shares their relics and who has none yet), `sortie` (sortie and Archon Hunt, then Archimedea, Steel Path honors and the weekly button; the Archon Hunt's thumbnail is the shard its archon drops (`archonShard`, `shardEmojiName`: Nira Amber, Amar Crimson, Boreal Azure), the archon icon when the shard is not known or has no custom emoji, and its missions share the heading's section, so no gap opens beside the picture; "Drops an Amber/Azure", "a Crimson"; the weekly post uses the same `archonPart` a heading lower (`###`); numbered mission lines escape the dot (`1\.`, `nth`), since Discord reads a line starting `**1. ` as a list and breaks it after the type), `cycles` (the open worlds with the next Eidolon nights and warm Vallis, then the Duviri Circuit with the "Incarnon weapon" button right under it, and the bounties with a `feeds:bounty` menu), `traders` (Baro's whole stock with ducats and credits, and plat per ducat and the best resale once the `baro-prices` job has priced it: `FeedInput.prices` = `baroPriceLookup`; Darvo, Varzia, Teshin) and `invasions`. `FEEDS` (index.ts) is the registry: the setting that holds its channel, a `version` (bump it when a layout changes, so every board is redrawn once) and `needsWorldState`. **A board pings nobody** (since 2026-11-11): what the Alerts, Arbitrations and Baro roles used to be pinged for are the trackers `notable`, `arbitration` with `minTier: 'A'` and `baro`, DM'd by the notifier (Notifications in `src/discord/CLAUDE.md`). One round (`syncFeeds`): a feed that moved or was switched off clears its board from the old channel (bot_meta `feed_channel:<id>`), and `removeNote` deletes the ping note an older version left under a board, in the old channel and in the current one. When the world state could not be read, the boards that need it stay as they are (`skipped`). `card`/`fit` (parts.ts) keep each card's text inside a budget (cut at a line, "…and N more"), so a busy day makes a board shorter, never an edit Discord refuses (4000 characters and 40 components a message); a board always has the same number of messages, so a quiet day never reposts it; a big Baro visit drops the icons on each line when they would not fit (`BARO_LIST_BUDGET`). The first round in the alerts channel deletes the old single summary and its note (bot_meta `alerts_summary:`/`alerts_note:`). Every board ends with a "🔔 DM me when…" menu (`feeds:track:<feed>`, `TRACK_OPTIONS` in controls.ts, at most 25 per board; a pick creates a tracker unless the member already has it or is at `MAX_TRACKERS_PER_USER`) and a "My notifications" button (`feeds:mine`: an ephemeral list with a `feeds:untrack` menu); the sortie board also has the "Weeklies by DM" button (`notify:weekly`); the cycles board has the "Incarnon weapon" button (`feeds:incarnon`, `incarnonButton`, which opens the `/track incarnon` dropdown in `track-pick.ts`) right under the Duviri Circuit, or in the bottom row before "My notifications" when there is no Circuit or no world state, and the weekly post and the roles panel have it too (it left the sortie board on 2026-11-16; the handler stays for older messages); the DM buttons always go in the order toggles, Incarnon, then "My notifications" last. Discord keeps a member's pick shown in a select menu until the message changes, so a menu answer first redraws the board message as it is (`shownComponents`, the components last sent per message id) and then answers with `followUp`. `feedHealth()` (`get_bot_health.feeds`) shows per board the channel, the last action, an error, and the longest message's text and component count. Set with `/setup feed board: channel:`, the panel's Settings page (World State boards) or MCP `update_bot_settings` (`<feed>_channel_id`); `/setup off feature:Board: …` switches one off; `assertChannelFree` gives each board a channel of its own.
