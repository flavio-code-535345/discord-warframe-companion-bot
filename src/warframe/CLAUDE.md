# Warframe data and the API client

Notes for this folder. The rules that apply everywhere, the commands and the list of the other notes are in the root `CLAUDE.md`.

**Warframe data** (`src/warframe/`):
- Worldstate is off by default (`WORLDSTATE_ENABLED=false`; switch it on in the Config page). It comes from the community warframestat.us API, `api.warframestat.us/<platform>` (`pc`, `ps4`, `xb1`, `swi`, chosen from `WARFRAME_PLATFORM`), which serves the already-parsed world state as JSON (dates are ISO strings, so go through `toMs`/`discordTime`/`relative` in `src/time.ts`, which tolerate strings and missing values). **Never call Digital Extremes' own `api.warframe.com`** (calling it yourself breaches their EULA, and a blocked IP can't log in to the game either; the clan's co-owner asked for it to be removed fully): `worldstate.ts` has no code for the raw feed, `WORLDSTATE_URL` only accepts a warframestat.us-compatible JSON endpoint, and `parse()` rejects anything else. The types still come from `warframe-worldstate-parser` (`import type` only, nothing from it is loaded at runtime). It is called at most once per `WORLDSTATE_POLL_SECONDS` (default 600): the last call (time, result, url) is kept in `bot_meta` and the answer in `<DATA_DIR>/worldstate.cache`, so restarts and deploys cause no extra calls (a record or validators for another url are ignored); after a failure it waits `retryAt`. **Smart polling** (option, `WORLDSTATE_SMART_POLL`, off by default; `WORLDSTATE_MAX_POLL_MINUTES`, default 30): instead of a fixed timer the next call is due at the soonest rollover (`nextRefreshDelay`: alerts, sortie, archon hunt, events, Baro arrival or departure, daily deals, Zariman and Duviri cycles, Steel Path rotation, bounties) plus 20 s, never sooner than `WORLDSTATE_POLL_SECONDS` and never later than the cap. Fissures are deliberately not rollovers (dozens of them, one is always about to end, so it would poll at the minimum all day); they refresh with the cap and ended ones are filtered out meanwhile. `cached.due` holds the due time, also computed for the answer reloaded from disk after a restart. `test/worldstate-smart.test.ts` uses a mocked Date. The status page shows a "World state" pill with the last call.
- warframe.market must use **API v2** (v1 returns 403 "Deprecated"). Its Cloudflare blocks Node's default User-Agent, so every outbound call goes through `apiFetch` in `src/warframe/fetch.ts`.
- Drop tables come from warframestat.us (`/drops/search/`), which still works.

**Third-party API client** (`src/warframe/fetch.ts`, `src/warframe/cycles.ts`): every outbound Warframe call goes through the one `ApiClient` (`api`; `apiFetch` for raw responses, `apiJson` for cached JSON with `kind: 'live' | 'price' | 'stable'`). It spaces requests per host (`API_MIN_INTERVAL_MS`, or a host's own wider gap in `hostIntervalMs`: AlecaFrame asks for one request a second), caps all hosts per minute (`API_RATE_LIMIT_PER_MINUTE`; background work such as the wiki crawler gets half and a queue longer than 10 s throws `ApiBusyError`), answers a 429 by leaving that host alone for its `Retry-After`, and a 403 by a cooldown (`API_COOLDOWN_MINUTES`) in which nothing is sent (`ApiBlockedError`, never retried). Server errors and timeouts retry `API_MAX_RETRIES` times with exponential backoff and jitter, except the statuses a caller lists in `send(..., { answer })`, which come back as they are with no retry and no cooldown (AlecaFrame answers a bad token with a 500). `api.get` caches successful answers in memory and in the `api_cache` table (bot.db; prices `API_PRICE_CACHE_SECONDS`, items/drops/wiki `API_STABLE_CACHE_HOURS`), shares identical in-flight requests, revalidates with ETag / Last-Modified, and when the host can't be used returns the expired entry with `stale: true` (limited by age per kind) instead of failing; errors are never cached. The world state keeps its own pacing (`WORLDSTATE_POLL_SECONDS`, `retryAt` after a failure, conditional request against `<DATA_DIR>/worldstate.cache`); `worldStateStaleNote()` says when what is shown is outdated, and `projectCycles` rolls Cetus, Vallis, Earth, Cambion, Zariman (150 min Grineer/Corpus) and Duviri (`rollDuviri`: Joy, Anger, Envy, Sorrow, Fear, 2 h each, from the wiki's Reset page; the feed's mood had been shown as "21 minutes ago") forward from their fixed phase lengths so cycles are right between polls (embeds, MCP, status page, and the cycle trackers, whose key rounds the expiry to the minute so a calculated and a real expiry never notify twice; the Duviri Circuit choices come from the feed). `SOURCE_LAG_MS`: when the source's own `timestamp` was more than 20 min older than the moment it was fetched (warframestat.us lags at times), `worldStateStaleNote()` says so (cycles and fissures embeds, MCP `warning`) and the status pill shows "source data N min behind". Settings live in the Config page ("API limits and cache", plus an activity card); `get_bot_health` shows `apiClient` stats. `test/api-client.test.ts` uses a fake clock and fetch.

**Lookups** (`src/warframe/items.ts`, `wiki.ts`): warframestat.us `/items/search` for stats (a relic's four refinements are merged into one result, and rarity is derived from the intact chance because the export's labels are unreliable). Drop chances in both warframestat.us APIs are already percentages. The wiki uses MediaWiki `list=search` plus TextExtracts.

**Arbitrations** (`src/warframe/arbitrations.ts`, `test/arbitrations.test.ts`): the hourly schedule years ahead comes from browse.wf (`SCHEDULE_URL`, lines of `unixSeconds,NodeId`; calamity-inc, MIT) and the S–F tiers from the Arbitration Goons' list in the same project (`TIERS_URL` on raw.githubusercontent.com; a node it doesn't rank is F), both read through the shared `ApiClient` as background `stable` data, revalidated twice a day and served stale when browse.wf can't be reached. Node names, mission types and factions come from `warframe-worldstate-data`'s solNodes.json in node_modules, so drawing the schedule makes no request. `arbitrationView` is pure (the current hour, the next ones, the best of the week by tier) and checks the schedule against the world state's own `arbitration` entry: when they name different nodes (the rotation was reseeded once before) `scheduleTrusted` is false, nothing from the schedule is shown or pinged, and the trackers use the world state's entry. Like the world state, this never touches api.warframe.com or any other Digital Extremes host.

**Relic values** (`src/warframe/relics.ts`, `test/relics.test.ts`): `loadRelicBook()` builds a `RelicBook` from WFInfo's two tables on warframestat.us (`/wfinfo/filtered_items`: each relic's six rewards by rarity, vaulted or not, every part's ducats; `/wfinfo/prices`: one plat average per prime part and set, from warframe.market's statistics), two `stable` requests every 6 h through the shared `ApiClient` (a restart asks nothing, stale data is served when warframestat.us is down), so valuing relics makes no warframe.market request (pricing the ~1,400 prime parts there would be hours of background reads). `relicValue(relic, refinement)` is pure: `slotChance` (one uncommon/the rare: Intact 11/2%, Exceptional 13/4%, Flawless 17/6%, Radiant 20/10%; a common is the rest split three ways), `solo` = the expected plat of one reward, `radshare` = the expected best of four rewards (each player takes the most valuable), and ducats; Forma and a reward without a price count as 0 and `complete: false` says so. `findRelic` takes any case, "Relic" and a refinement after the name; `bestRelics` ranks by refinement, squad, vaulted filter and tier. Used by `/relics` (`bestRelicsEmbed`), the relic card (`relicEmbed(relic, book)`: each reward's price and a "Worth per run" field; `/item` and the chat's relic answers pass the book), MCP `relic_values` and the AlecaFrame relic planner. What relics themselves sell for is not used: warframe.market has too few live orders per refinement for a fair price.

**Baro prices** (`src/warframe/baro.ts`, `test/baro-prices.test.ts`): while Baro is at a relay the `baro-prices` job prices his stock on warframe.market, one item every 20 s (`BARO_PRICE_MS`) as background work in its own `baro` scope: `topOrders(slug, { rank: 0 })` for a mod (he sells them unranked) and `marketPrice` (market.ts: the median of the five cheapest online sellers); an item the market's index doesn't list under exactly that name (cosmetics, the Void Surplus) is recorded as unpriced without a request, and each item is read again after 6 h. A full budget waits a minute, a cooldown until it ends; any other failure retries that item in 30 min and fails the round. The prices of the current visit live in bot_meta `baro_prices` (a restart reads nothing again, a new visit starts over); between visits the job sleeps until he lands, at most 30 min at a time. `baroPriceLookup(store, ws)` is `FeedInput.prices`, so the traders board shows plat per ducat per item and the best resale; the status page's Baro tile uses the same lookup.

**Web search** (`src/warframe/websearch.ts`, `SEARXNG_URL`): a self-hosted SearXNG (the one in the Odysseus `ai-stack`, published on a LAN port; its settings must enable `formats: json`) backs the `search_web` MCP tool, limited to Warframe hosts (`ALLOWED_HOSTS`, Reddit only from the Warframe subreddits). A 6 s timeout and any failure just mean no results. Chat answers never use it.
