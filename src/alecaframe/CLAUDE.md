# AlecaFrame

Notes for this folder. The rules that apply everywhere, the commands and the list of the other notes are in the root `CLAUDE.md`.

**AlecaFrame** (`src/alecaframe/`, `src/discord/commands/alecaframe.ts`, `src/discord/alecaframe-embeds.ts`, `test/alecaframe.test.ts`; migration 37 `alecaframe_links`): opt-in per member. `/alecaframe link token:` takes the public-link token from AlecaFrame's Stats tab (or the whole link, `tokenFrom`), checks it with one read and stores it with the username and what it shares (`parts`, AlecaFrame's PublicLinkParts flags in `SHARES`); the token is read-only and revocable in AlecaFrame, and only its owner's commands use it. `api.ts`: `fetchStats` (`stats.alecaframe.com/api/stats/public?token=`; `parseStats` keeps the data points and trades, never trade partners' names) and `fetchRelics` (`/getRelicInventory?publicToken=`, a JSON-quoted base64 binary list, `parseRelicInventory`); answers stay 10 min in memory per token and are never stored (`forgetToken` on unlink). AlecaFrame reports a bad token as HTTP 500 with `detail: "Invalid token"`, so its statuses go through `answer` and become a `UserError` that explains how to make a link, with no retry and no cooldown. `/alecaframe stats [period] [share]` (private unless `share`) sends `alecaStatsEmbed` with a picture from `drawStatsChart` (`chart.ts`, pureimage drawn at 2x and averaged down: a panel per shared currency with its change, low/high and an area line; `statSeries` carries the last reading before the period in); `/alecaframe relics` uses `planRelics` (`planner.ts`: the relics to open by value, and the refinements worth their Void Traces) with the relic book; `/alecaframe unlink` removes it. The link checks run before the reply is deferred, so a missing link is answered privately even with `share`. AlecaFrame's overlays (its riven analyzer) and anything the public link doesn't share are out of reach.
