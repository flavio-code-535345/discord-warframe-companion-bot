# Birthdays

Notes for this folder. The rules that apply everywhere, the commands and the list of the other notes are in the root `CLAUDE.md`.

**Birthdays** (`src/birthdays/service.ts`, `/birthday set|remove|list`; table `birthdays`, day and month only): from 07:00 UTC the notifier wishes the members still in the server whose birthday it is (29 February on the 28th in other years); bot_meta `birthday_posted` = the day done.
